Decision Threshold

Active Session | v1.0

Definition

The decision threshold is the probability value at which a classification model assigns a positive or negative class. The default is usually 0.5.

How it works

If the estimated probability by the model is greater than or equal to the threshold → positive class. If it is less → negative class.

Impact on metrics

  • Low threshold (e.g., 0.3): increases recall, decreases precision.
  • High threshold (e.g., 0.7): increases precision, decreases recall.

Real example

In fraud detection, the threshold is lowered to catch more suspicious cases, even if it increases false positives. In marketing, the threshold is adjusted to capture more potential customers.
