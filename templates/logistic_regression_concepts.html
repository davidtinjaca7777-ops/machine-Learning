Logistic Regression – Concepts

What is Logistic Regression?

It is a statistical model used for binary classification problems. It estimates the probability of an event occurring (e.g., purchase/no purchase) using the sigmoid function, which transforms values into a range between 0 and 1.

Why is it considered classification?

Because it does not predict continuous values, but discrete categories. The model calculates probabilities and applies a threshold (e.g., 0.5) to assign each observation to a class.

Binary Classification

Refers to problems where the target variable can only take two possible values: yes/no, true/false, positive/negative. Logistic regression is designed for this type of tasks.

Independent Variable

These are the input features or attributes (X) that influence the outcome. They can be numerical (age, income) or categorical (gender, region). Their correct selection and preparation is key to the quality of the model.

Dependent Variable

It is the target variable (y) that we want to predict. In logistic regression, it must be binary, for example: 0 = No purchase, 1 = Purchase. The model estimates the probability of y = 1 given X.

Classes or Labels

Represent the categories of the dependent variable. Example: 0 = healthy, 1 = sick. A clear definition of the classes ensures that the predictions are useful and actionable.

Membership Probability

The model returns a probability between 0 and 1 of belonging to a class. A threshold is applied to decide the final classification. This threshold can be adjusted according to the context (e.g., in medicine, it is lowered to detect more positive cases).
